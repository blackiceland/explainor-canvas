# omni — конвейер OmniHuman 1.5 через fal.ai

Консольный инструмент: кладёшь фото + аудио в папку, запускаешь одну команду — получаешь готовые MP4.
Модель ничего не решает в момент генерации: это обычный CLI, который сам загружает файлы в fal,
ставит задачи в очередь, ждёт, скачивает результат и возвращает в видео исходный аудиомастер.

Эндпоинт: `fal-ai/bytedance/omnihuman/v1.5`. Цена — **$0.16 за секунду** видео (30 с ≈ $4.80).

## Установка

```bash
cd omni
npm install
cp .env.example .env      # и вписать FAL_KEY из https://fal.ai/dashboard/keys
node bin/omni.mjs doctor  # проверка ключа, ffmpeg и связи с fal
```

`ffmpeg`/`ffprobe` ставить отдельно не нужно — они приезжают вместе с зависимостями.
Чтобы вызывать просто `omni`, один раз сделай `npm link` в этой папке.

## Один клип

```bash
node bin/omni.mjs gen photo.jpg song.wav --res 720p --prompt "спокойное пение, лёгкое покачивание"
```

## Пачка

```bash
node bin/omni.mjs batch ./clips --res 720p --concurrency 3 --limit-usd 25
```

Поддерживаемые раскладки папки:

```
clips/alice/{photo.jpg, song.wav, prompt.txt}   одна подпапка = один клип
clips/{alice.jpg, alice.wav}                    плоско, по совпадающим именам
clips/{artist.jpg, track1.wav, track2.wav}      одно фото на несколько треков
```

Промпт берётся в порядке: `--prompt` → `<имя_трека>.txt` → `prompt.txt` рядом → `prompt.txt` в корне папки.

## Деньги

- `--dry-run` — посчитать стоимость и выйти, ничего не потратив.
- `--limit-usd N` (по умолчанию 25) — запуск не стартует, если смета выше.
- Перед стартом спрашивается подтверждение; `-y` его пропускает.
- Секунды берутся из реальной длительности аудио через `ffprobe`, поэтому смета точная.

## Лимиты и обрезка

1080p принимает аудио до 30 с, 720p — до 60 с. Если трек длиннее, клип не отправляется
(деньги не тратятся). Варианты: `--res 720p`, `--trim` (обрезать до лимита) или порезать трек самому.

## Аудио

По умолчанию из готового ролика достаётся видеодорожка, и под неё подкладывается исходный
мастер (`-c:v copy`, AAC 320k). Отключается флагом `--no-remux`.

## Ничего не теряется

Каждый запуск пишет `.omni/jobs.jsonl` рядом с исходниками: id запроса, длительность, стоимость, путь результата.

- повторный запуск пропускает клипы, уже сделанные с теми же входами и параметрами (`--force` — переделать);
- если процесс упал после отправки, `node bin/omni.mjs jobs ./clips` покажет незавершённые запросы
  и готовую команду `omni fetch <requestId> --out <файл>`, чтобы забрать оплаченный результат;
- одинаковые файлы (общее фото на всю пачку) заливаются в fal один раз на 12 часов.

## Команды

| команда | что делает |
| --- | --- |
| `gen <image> <audio>` | один клип |
| `batch <dir>` | все клипы в папке |
| `jobs [dir]` | сколько потрачено и что не завершено |
| `fetch <requestId> --out <file>` | забрать результат по id |
| `cancel <requestId>` | отменить задачу в очереди |
| `doctor` | проверка окружения |

`node bin/omni.mjs --help` — полный список флагов.
